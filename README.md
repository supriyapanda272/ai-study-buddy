# AI Study Buddy

A beginner-friendly Python project designed to help students study.

## Features

- Answer basic study questions
- Create a simple study plan
- Summarize notes by selecting the first two sentences
- Take a Python quiz and calculate the score

## Requirements

- Python 3

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python app.py

## Technologies Used

- Python
- Visual Studio Code
- Git and GitHub

## Current Limitations

This version uses predefined answers and a basic
sentence-selection summarizer. It does not yet use
a live AI model.

## Future Improvements
